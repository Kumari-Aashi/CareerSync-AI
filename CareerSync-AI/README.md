# CareerSync AI

AI-Powered Career, Skill & Placement Management System — Final Year CSE Major Project.

## Demo
Open `frontend/index.html` in a browser, or use VS Code Live Server.

## Stack
- HTML, CSS, JavaScript
- Python + Flask
- MySQL
- C++ for DSA/OOP
- Python AI/NLP modules

## Demo pages
- Student: `frontend/student/dashboard.html`
- Company: `frontend/company/dashboard.html`
- Admin: `frontend/admin/dashboard.html`

## Backend
```bash
python -m venv venv
venv\Scripts\activate
pip install -r backend/requirements.txt
python backend/app.py
```

## Database
Create a MySQL database and run `database/schema.sql`.

## Notes
The included website is a polished frontend prototype with demo interactions. The Flask API, SQL schema, AI modules and C++ DSA modules are included as the foundation for connecting the full production workflow.
